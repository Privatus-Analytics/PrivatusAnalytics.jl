PrivatusAnalytics.PrivatusAnalytics — Module
PrivatusAnalytics

Adds the cookieless Privatus Analytics tracking script to Julia web apps and sites.

The package only prints HTML: the browser script tag and a few data attributes. It never sends events from the server, sets no cookies and reads nothing about your visitors.

Start with configure! and tag. See the README for Genie, HTTP.jl, Franklin and Documenter.

PrivatusAnalytics.Configuration — Type
Configuration(; kwargs...)

Settings for the tracking script. Every setting is optional except the site id.

  • site_id: the site id (starts with pa_). Falls back to ENV["PRIVATUS_SITE_ID"].
  • script_host: origin that serves /js/pa.js. Falls back to ENV["PRIVATUS_SCRIPT_HOST"], then https://privatusstats.com.
  • modules: tracker modules to load, for example ["engage", "auto"]. nothing keeps the tracker default. String[] loads none.
  • excluded_paths: path globs the tracker never counts, for example ["/admin/*"].
  • domains: hostnames to count. nothing counts every host.
  • spa: one of "auto", "history", "hash", "off". nothing keeps the tracker default.
  • manual: true turns off the automatic pageview.
  • enabled: true or false forces the tag on or off. nothing turns it on only when ENV["GENIE_ENV"] == "prod" or ENV["PRIVATUS_ENV"] == "production".
  • auto_inject: true adds the tag to every HTML page of a Genie app.
  • extra_attributes: other data-* attributes, for example Dict("data-mask" => "/orders/*->/orders/:id").
  • props: page props sent with every pageview and event, for example (plan = "pro",). A NamedTuple, Dict or list of pairs, or a function called on each request: req -> (plan = plan_for(req),). Never put names, emails, user ids or anything else that points to one person here.
  • queue_stub: true prints the tracker's queue stub first, so privatus.track works before pa.js loads.
  • nonce: a Content Security Policy nonce for the script tags. A string, or a function called on each request.
PrivatusAnalytics.SafeHTML — Type
SafeHTML(html)

A string of HTML that is already escaped and safe to print as is.

It works anywhere a String works (string interpolation, print, *, HTTP bodies), and it shows as real HTML in tools that understand the text/html MIME type, like Pluto, Jupyter and Documenter @example blocks.

PrivatusAnalytics.click_attr — Method
click_attr(name) -> SafeHTML

The click map name attribute as escaped HTML: data-privatus-click="pricing.cta". Prints nothing when the name is not valid.

PrivatusAnalytics.click_data — Method
click_data(name) -> Vector{Pair{String,String}}

The click map name as "data-privatus-click" => name, or an empty list when the name is not valid. Outside production it logs a warning for a name that is not valid.

PrivatusAnalytics.configuration — Method
configuration() -> Configuration

The global settings used by tag and the integrations.

PrivatusAnalytics.configure! — Method
configure!(; kwargs...) -> Configuration

Changes the global settings. Takes the same keywords as Configuration.

PrivatusAnalytics.configure!(site_id = "pa_YOURSITEID", modules = ["engage", "auto"])
PrivatusAnalytics.escape_html — Method
escape_html(value) -> String

Escapes & < > " ' so a value is safe inside an HTML attribute or element.

PrivatusAnalytics.event_attrs — Function
event_attrs(name, props = nothing; more_props...) -> SafeHTML

Data attributes for a custom event, as escaped HTML to put inside a tag:

"<button $(event_attrs("Report exported"; format = "csv"))>Export</button>"

On a <form> the event is sent when the form is submitted. Prints nothing for an empty name. The attributes print even when the tag is off, so your pages look the same everywhere.

PrivatusAnalytics.event_data — Function
event_data(name, props = nothing; more_props...) -> Vector{Pair{String,String}}

The custom event attributes as attribute name => value pairs, with values not yet escaped. Use it with HTML builders that escape values for you. Returns an empty list for an empty name.

event_data("Report exported"; format = "csv")
# ["data-privatus-event" => "Report exported", "data-privatus-prop-format" => "csv"]
PrivatusAnalytics.inject — Function
inject(html, config = configuration(); request = nothing, overrides...) -> String

Puts the tag just before </head>. Leaves the page alone when it already has the tag, has no </head>, or when the tag is off. Takes the same keywords as tag.

Handy for static pages too, for example after a Franklin or Documenter build.

PrivatusAnalytics.inject_response — Function
inject_response(request, response; config = configuration(), nonce = nothing)

Adds the tag to one HTTP.Response when injectable allows it. Used by middleware and by the Genie integration. Needs HTTP.jl.

PrivatusAnalytics.injectable — Method
injectable(status, content_type, content_encoding, requested_with) -> Bool

Whether a response may get the tag: status 200, text/html, no Content-Encoding, and not an Ajax request (X-Requested-With: XMLHttpRequest). Missing headers are empty strings.

PrivatusAnalytics.isenabled — Function
isenabled(config = configuration()) -> Bool

Whether the tag should print. enabled wins when it is true or false. Otherwise the tag is on only when ENV["GENIE_ENV"] == "prod" or ENV["PRIVATUS_ENV"] == "production".

PrivatusAnalytics.isvalid_click — Method
isvalid_click(name) -> Bool

Whether a click map name is valid: letters, digits, _ . : - and at most 100 characters.

PrivatusAnalytics.middleware — Function
middleware(handler; config = nothing, nonce = nothing)

HTTP.jl middleware that adds the tag just before </head> in HTML responses. Needs HTTP.jl: run using HTTP first.

using HTTP, PrivatusAnalytics
HTTP.serve(PrivatusAnalytics.middleware(router), "0.0.0.0", 8080)

It skips responses that are not status 200 text/html, compressed responses (with a Content-Encoding header), Ajax requests, pages without </head> and pages that already have the tag. It sets Content-Length to the new size. config defaults to the global settings at request time. nonce is a string, or a function that gets the request.

PrivatusAnalytics.normalize — Method
normalize(props) -> Vector{Pair{String,Any}}

Cleans every key with normalize_key, drops nothing values and empty keys, and keeps the first 30 props.

PrivatusAnalytics.normalize_key — Method
normalize_key(key) -> String

Lowercases a prop key, swaps anything outside a-z 0-9 _ for _ and cuts it to 64 characters. "Report Type" becomes "report_type".

PrivatusAnalytics.page_props — Function
page_props(config = configuration(), request = nothing)

The configured props for one request. Calls props when it is a function: with the request when it takes one argument, or with no arguments.

PrivatusAnalytics.page_props_json — Method
page_props_json(props) -> Union{String,Nothing}

A JSON object string, or nothing when there are no props to send. <, >, &, U+2028 and U+2029 are written as \u003c and so on, so the JSON is safe inside a <script>.

PrivatusAnalytics.privatus_analytics_tag — Function
privatus_analytics_tag(; kwargs...)

The script tag for a Genie view, as a Genie ParsedHTMLString. Needs Genie: run using Genie first. It passes the current Genie request to a props or nonce function. Takes the same keywords as tag.

<head>
  <title>My app</title>
  $(privatus_analytics_tag())
</head>
PrivatusAnalytics.privatus_click_data — Function
privatus_click_data(name) -> Vector{Pair{Symbol,String}}

The click map name for Genie's HTML functions, escaped. Empty when the name is not valid. Needs Genie.

<% Html.a("See plans"; href = "/pricing", privatus_click_data("pricing.cta")...) %>
PrivatusAnalytics.privatus_event_data — Function
privatus_event_data(name, props = nothing; more_props...) -> Vector{Pair{Symbol,String}}

The custom event attributes for Genie's HTML functions (Html.button and friends), with every value already escaped, because Genie prints attribute values as they are. Needs Genie.

<% Html.button("Export"; class = "btn", privatus_event_data("Report exported"; format = "csv")...) %>
PrivatusAnalytics.render — Function
render(config = configuration()) -> Bool

Whether the tag prints: there is a site id and the tag is enabled.

PrivatusAnalytics.reset_configuration! — Method
reset_configuration!() -> Configuration

Puts every setting back to its default. Handy in tests.

PrivatusAnalytics.script_attributes — Function
script_attributes(config = configuration(), nonce = nothing) -> Vector{Pair{String,Any}}

The tracker tag's attributes, in order. true means an attribute without a value (defer).

PrivatusAnalytics.script_host — Function
script_host(config = configuration()) -> String

Where /js/pa.js is served, without a trailing slash.

PrivatusAnalytics.site_id — Function
site_id(config = configuration()) -> Union{String,Nothing}

The configured site id, else ENV["PRIVATUS_SITE_ID"], else nothing.

PrivatusAnalytics.tag — Function
tag(config = configuration(); request = nothing, props = nothing, overrides...) -> SafeHTML

The Privatus Analytics script tag, as escaped HTML for the <head> of your page:

PrivatusAnalytics.tag()
# <script defer src="https://privatusstats.com/js/pa.js" data-site="pa_YOURSITEID"></script>

Without a site id, or when the tag is not enabled (see isenabled), prints only the queue stub when queue_stub is on, and otherwise nothing.

  • Any setting of Configuration can be changed for this call, for example tag(modules = ["engage", "auto"], nonce = "abc").
  • props are merged over the configured props. A nothing value removes one.
  • request is passed to a props or nonce function.
PrivatusAnalytics.to_html — Method
to_html(attrs) -> String

Turns name => value pairs into HTML attributes, with every value escaped.

PrivatusAnalytics.with_overrides — Function
with_overrides(config; overrides...) -> Configuration

A copy of config with some settings changed. The original is left alone.
